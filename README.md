A make.fun entry for [The Funniest Sick-Day Excuse](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36).

`main.ts` (Node 24, stdlib only) writes one line — 144 characters — to `/output/entry.txt`:

> My car won't start — a squirrel has moved into the engine and is now, legally speaking, the registered keeper. I'm home negotiating an eviction.

Half believable (squirrels really do nest in car engines), fresh (no fever, no dog, no dead grandmother), and the laugh lands on the last word: the driver is home negotiating an eviction with a squirrel that now legally owns the car. It reads like a real person texting their boss, not a joke built for a contest.

Run it with:

```sh
node main.ts
```
